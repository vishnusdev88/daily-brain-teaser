Privacy Policy

Last updated: 19 October 2026

"Daily Brain Teaser" is a small automation tool run by its owner to publish one short puzzle video each day to the owner's own YouTube channel, Facebook Page and Instagram account. It is not a public app and is not used by anyone else.

What the tool accesses

With the owner's permission (given through Google and Meta sign-in screens), the tool can upload videos and post comments to the owner's own YouTube channel, Facebook Page and Instagram professional account. It uses only the permissions needed for that.

What we collect and store

The tool does not collect personal information from visitors, viewers or commenters, and it does not run advertising or analytics. The only sensitive items stored are the owner's own access tokens, kept in the owner's private settings (an environment file and encrypted GitHub secrets). They are not shared with anyone.

Use and sharing of Google user data

Access to the owner's YouTube account is used only to upload the owner's puzzle videos and post comments on them. Google user data is not sold, shared with third parties, or used for advertising. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Access tokens are kept only while the tool is in use. The owner can revoke access at any time at myaccount.google.com/permissions (Google) and in the Business Integrations settings of Facebook and Instagram.
